# v0.8.4 — 2026-11-10 (review reminders and deep links)

## Status the bot can answer
- `dream_cycle_review_status` reads this profile's review ledger. Pending
  review (including reverted) is separate from accepted-and-not-yet-applied.
  Both zero means nothing is waiting.
- `dream_cycle_snooze` and `/dream-cycle snooze` pause proactive reminders
  for seven days. An explicit question still returns the live status.
- The plugin skill and, when the host allows it, a system-prompt section tell
  the bot to call the tool instead of guessing. Memory files are not edited
  to teach this.

## Proactive reminder
- Unreviewed dreams older than seven days (strictly more than `overdue_days`).
- At most once per rolling `cooldown_hours` (default 24) per profile.
- Snooze suppresses nags only. After it ends, one nag may go out; missed days
  are not replayed.
- A failed confirmed delivery does not set `last_sent_at`, so it can be retried.
- A cron emit sets `last_emit_at` only. That is the daily cap for the
  scheduler handoff, not a receipt.

## Dashboard
- `/oneiros?profile=<name>&day=YYYY-MM-DD` loads that profile and that night.
- Snooze is `POST /reminder/snooze`. GET does not snooze.

## Schedule
Copy `scripts/review-reminder.py` to `$HERMES_HOME/scripts/` and create a
Hermes cron job with `--no-agent`, that script, and `deliver: origin`.
Empty stdout stays silent. The origin chat is the conversation where the job
was created (or the profile home channel if origin was not captured). This
plugin does not name a chat id and does not call a model to decide.
