# v0.4.1 — 2026-11-09 (cross-day decisions)

## Cross-day review carry
- `undecided()` and `status` consult the latest decision for a `proposal_id`
  across all `dream-proposals/*/review.jsonl` (not only today's folder).
- On `propose`, a prior **reject** or **defer** is copied into today's ledger
  with `carried_from: <day>` so the trail is auditable and status stays quiet.
- **Accepts are never carried.** `apply --accepted` only acts on an accept in
  *today's* stage; apply still refuses when the live file sha no longer matches
  the staged proposal. A prior-day reject still blocks apply even if today's
  ledger has not yet been carried.
- Fixes a profile's nightly re-staging of `df6aae120cb3` (ports 8080 vs 8089) after
  the 2026-11-08 reject.
