# v0.6.0 — 2026-11-09 (state.db session dreams)

## Feature
- Propose compares MEMORY.md to **recent sessions in the profile `state.db`**
  (read-only: `mode=ro` + `PRAGMA query_only`). No writes, no migrations.
- `session_corroboration.source: state.db` (default when enabled) with
  `lookback_days` (default 3). Legacy `command` source still works.
- Session-sourced proposals carry `session_ids` + `session_evidence`
  (message id, session id, line_sha256, short snippet) for the dashboard.
- Still **model-free** — local and cloud-backed profiles use the same
  deterministic path; no LLM step was added.

## on_session_open (optional)
- Feature-detect register: warm status / Waking Check cache before first CLI/TUI/Desktop turn.
- Callback signature: `session_id`, `platform`, `reason` (`create`|`resume`), `**kwargs`.
- No-op on Hermes v0.23.0 (`VALID_HOOKS`); never raises; no Hermes upgrade required.
- Writes `plugin-data/dream-cycle/session-warm.json`; stays well under the 5s turn-wait budget.
