# v0.8.1 — 2026-11-09 (one-click accept + Accept all)

## Dashboard
- **Accept** on each proposal row is one click: keeps the first listed value,
  writes `review.jsonl` only, and does not apply to bot memory. Evidence is
  optional.
- **Accept with note…** still opens the dialog so you can change KEEP or add
  evidence. **Write accept** is enabled with an empty Evidence field.
- **Accept all** accepts every pending proposal currently shown (the active
  profile / day list), same default KEEP, no evidence. A bar reports the count
  and offers **Undo**.
- Undo appends a `reverted` row per proposal in that batch. The ledger is
  append-only — lines are never deleted. A reverted proposal is pending again.
  If a proposal was already changed after the batch, it is left alone.
- Apply-to-memory is unchanged: **Apply accepted…** still requires evidence
  and `apply_enabled`, and is a separate gated step.

## API / CLI
- `POST /review` accept no longer requires evidence (empty string is stored).
  `keep` is still required.
- `POST /review/accept-all` and `POST /review/undo-batch` (batch tagged on
  the accept rows). CLI `review append` already allowed empty `--evidence`.

## Tests
- `tests/test_dashboard_api.py` covers empty-evidence accept, accept-all,
  undo (append-only + memory untouched), and id-filter / skip-decided.
- `tests/test_dashboard_decision_ui.py` asserts the new buttons and optional
  evidence in `dashboard/dist/index.js`.
