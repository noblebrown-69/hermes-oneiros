# v0.7.0 — 2026-11-09 (learn about the person)

## Feature
- New **user-fact extractor** (`dream_cycle/user_facts.py`): reads **only**
  `role=user` messages from `state.db` (read-only). No model calls. No network.
- Categories: `PERSON`, `EVENT`, `PREFERENCE`, `STATUS`.
- Assertion gate: first-person / explicit `X is my …` forms only. Questions
  (`Who is X?`), gift-name drops, hypotheticals, compaction handoffs,
  discussion/cron system prompts, and assistant/tool text are skipped.
- Placement: people/preferences/status → `USER.md`; dated trips/appointments →
  `MEMORY.md` as `STATUS: … (revisit after YYYY-MM-DD)`.
- Each proposal carries session evidence (session id, message hash, short
  snippet), confidence, optional expiry, and `action: append`.
- Dedup against existing file text; respects MEMORY/USER char limits.
- Apply path supports append + rollback for user-fact proposals (still gated;
  propose-only by default until a guardian accepts).
- Demo: `./scripts/demo-userfacts.sh` (synthetic scratch profile only).

## Config
```yaml
user_facts:
  enabled: true
  lookback_days: 30
  max_rows: 8000
  categories: [PERSON, EVENT, PREFERENCE, STATUS]
```
