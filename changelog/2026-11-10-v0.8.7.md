# v0.8.7 — 2026-11-10 (configurable profiles, public scrub)

## Dashboard
- `profile_allowlist` replaces the built-in list of profile names. Leave it
  empty (the default) and every profile with the plugin installed is in scope.
  A non-empty list limits `oneiros_target_profile` to those directory names.
- A profile without the plugin gets a generic install message.

## Scrub
- `scripts/scrub-check.sh` checks generic secret and home-path patterns only.
- Extra name patterns belong in gitignored `scripts/scrub-local.txt`
  (one extended regex per line). The published script does not list them.
