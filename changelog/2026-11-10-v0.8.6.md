# v0.8.6 — 2026-11-10 (apply a whole file in one click)

## Apply
- **Apply accepted** no longer stops after the first write to a file.
  A night of accepts that share MEMORY.md or USER.md used to land one
  receipt per file and refuse the rest: the first write changed the hash
  and shifted line numbers, so the siblings looked stale.
- Sibling writes in the same click are remapped. A cited line whose text
  actually changed, and any edit from outside this batch, is still refused.
- `apply-refused` ledger rows now include a non-empty `reason` (the same
  text as `evidence`). The live refusals had hashes and a blank reason.

## Unchanged
- `apply_enabled`, the kill switch, the sha re-check, same-line conflicts,
  secret scan, snapshots, and rollback. Roll back receipts from newest to
  oldest to restore a file that took several writes.
