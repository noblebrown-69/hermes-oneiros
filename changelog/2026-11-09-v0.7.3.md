# v0.7.3 — 2026-11-09 (broader user facts)

## Feature
- PERSON also catches third-person role assertions (`X is a teacher`,
  `X is currently a <role>`, `X is my/our …`) when X is a capitalized proper
  name. Household context (`in my household`) is accepted. Kinship forms are
  unchanged.
- EVENT also stages dated shows/competitions (`Primary target: … June 12, 2028`,
  fallback show dates) and interviews (`Technical round Tue 11/10`), with
  expiry the day after the event.
- STATUS stages first-person job-search assertions
  (`I'm employed … looking for a new one` → `employed, actively searching`).

## Fix
- Require a real capitalized proper name after kinship (`my dad Makes` is not
  a name). Regression: `My dad makes …` no longer yields PERSON `makes — dad`.
- Two trip proposals for the same place with nearby dates collapse to one:
  an explicit dated itinerary supersedes an earlier relative "week or so".
- Trip expiry uses the end of the stay when a range or `through 11/22` is
  stated, not the first date + 1 day. Document metadata dates (`Prepared Nov 9`)
  are ignored when dating a trip.

- Drop EVENT proposals whose expiry is already before the dream day (so a
  10/29 recruiter screen is not restaged on 11/09). Uses the dream date, not
  the source-message date.
- Ignore verb/headline "show" ("has to show", "Fashion Show") and junk names
  from pasted articles so finance headlines do not become show events.
