# v0.8.3 — 2026-11-10 (apply dialog stays on screen)

## Dashboard
- **Apply accepted** no longer stacks every raw dry-run into one scrolling
  sheet. A large batch was taller than the viewport, so the title and
  Apply / Cancel left the screen.
- The dialog is a column: summary, a bounded preview, and a footer that stays
  put. Each proposal is one line (ready or blocked). The diff opens from that
  row. The preview scrolls on its own and does not chain into the page.
- Confirm is still explicit. `apply_enabled`, the kill switch, the sha
  re-check, and stale / conflicting refusals are unchanged.

## Deploy
Same static files as v0.8.2: `dashboard/dist/index.js` and
`dashboard/dist/style.css`, plus `plugin.yaml` and `dashboard/manifest.json`
for the version. Reload the plugin host when you choose; this does not
restart services.
