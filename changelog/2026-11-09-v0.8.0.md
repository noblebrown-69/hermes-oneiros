# v0.8.0 — 2026-11-09 (honor "do not save")

## Feature
- New `dream_cycle/nosave.py`: deterministic scan of role=user messages for
  don't-save / off-the-record directives. No model calls. No network.
- Phrases include `don't save` / `do not save`, `don't remember this`,
  `off the record`, `forget I said`, `don't log`, `keep this between us`,
  and `not for memory`.
- Scope: the exchange (that user message plus the following non-user turns)
  when the phrase appears mid-session; the whole session when it is in the
  first real user message or names "this whole conversation" (or equivalent).
- User-fact extraction and session corroboration both honor the skipped
  ranges. `honor_nosave` defaults to true and can be turned off in config.
- Status shows session/exchange skip counts and reason codes, never message
  text. The review ledger records `nosave-skip` rows with message and
  session hashes only (same-day re-runs do not duplicate rows).
- Quote / negation guards: quoted or fenced text, questions about the
  feature (`if I say don't save…`), first-person declaratives
  (`I don't remember`, `I don't save receipts`), and log-looking lines
  do not trigger.
- Demo: `./scripts/demo-nosave.sh`.

## Fix
- `test_propose_session_vs_memory_cites_evidence` now uses a fixed clock
  (messages on 2026-11-08, run_date 2026-11-09) so it no longer fails
