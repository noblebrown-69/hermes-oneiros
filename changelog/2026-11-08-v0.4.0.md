# v0.4.0 — 2026-11-08 (review items 2 + 3)

## Freshness status
- `status` (CLI, `dream_cycle_status` tool, `/dream-cycle status`) now reports last run time + age with a
  freshness grade (fresh ≤ 26 h / stale / never-run), files scanned last run (loud WARN on 0), proposals,
  undecided count recomputed against review.jsonl now, last receipt (id, applied/rolled-back, time,
  evidence status), apply_enabled, kill switch, require_grounded_evidence, and stale-format stages.
- Human block: `/dream-cycle status`, `hermes dream-cycle status --text`, and the tool's `text` field.

## Evidence grounding
- At apply, `keep` is checked against the dreamed day's + stage day's `state.db` messages (read-only),
  plus any `session_ids` a proposal cites. Roles default to `user` + `tool` (assistant text is the
  model's own claim). Receipt and review.jsonl rows carry `evidence_status: grounded|unverified` and
  matches as session id / message id / sha256 of the matching line — never the text.
- `require_grounded_evidence: true` refuses unverified applies (logged as `apply-refused`). Default false.

## Demo
- `scripts/demo-apply.sh`: status → propose → dry-run → accept row → apply --accepted → SUPERSEDED
  line + receipt → rollback → status → guard refusals. Synthetic memory + synthetic state.db only.

The v0.3.1 safe-write guard (MEMORY.md.lock, CAS, line scope, same-line, stale) is unchanged. 109 tests.
