# v0.6.2 — 2026-11-09 (arXiv / DOI ids are not ports)

## Fix
- Value extraction skips arXiv / DOI / `YYYY.NNNNN` paper ids so
  `arXiv:2611.00463` (and bare `2611.00463v2`) cannot stage as a port.
- Default port regex also refuses `:NNNN` when immediately followed by `.digits`.
- New helper: `markers.in_paper_id` (same shape as `in_iso_date`).
