# v0.8.5 — 2026-11-10 (tool manifest + next-turn reminder)

Not active until the plugin host reloads. No gateway restart is performed here.

## Tools
- `plugin.yaml` `provides_tools` now lists `dream_cycle_review_status` and
  `dream_cycle_snooze`, matching `register()`. Hosts that catalog or validate
  from the manifest were only advertising the five older tools.
- `provides_hooks` lists `pre_llm_call`. The prompt section is still
  registered when the host exposes `register_system_prompt_section`.

## Desktop, dashboard, and API
- Cron `deliver: origin` does not reach these chats. It needs a live session
  platform and chat id, and an `api_server` origin is not a push target.
- When this Hermes lists `pre_llm_call` (v0.23.0 does), a due reminder is
  attached to the next private owner turn as context. The model is asked to
  mention the count, the link, and snooze. Nothing is pushed while the user
  is idle.
- Groups, channels, threads, and messaging chats with no DM type are skipped.
  Skipping does not consume the 24 hour cap.
- The seven-day threshold, rolling 24 hour cap, seven-day snooze, and the
  on-demand status tool are unchanged.

## Optional push
- `scripts/review-reminder.py` stays available for a cron transport that
  really has an origin chat. It is not the path for Desktop or API.
